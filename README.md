# 🎓 Atria Fee Management System – Frontend

This is the frontend application for the **Atria Fee Management System**, providing an easy-to-use interface for students and administrators to manage fee records and interact with the backend services.

The frontend is built with modern web technologies and deployed on **Vercel**.

---

## 🚀 Live Application

🌐 Frontend URL:  
https://fee-osx8.vercel.app

⚙️ Backend API URL:  
https://fee.centralindia.cloudapp.azure.com

---

## 🧰 Tech Stack

- React.js / Next.js  
- Tailwind CSS / CSS  
- Axios (for API communication)  
- Vercel (Hosting & Deployment)

---

## 📦 Features

- User Authentication (Login & Logout)  
- Student Fee Dashboard  
- Fee Records Display  
- Secure API Integration  
- Responsive User Interface  

---

## 🔗 API Integration

The frontend communicates with the backend hosted on Azure:

https://fee.centralindia.cloudapp.azure.com
